# Lessons and problems: sources and licences

* `lessons/` -- the ten tutorial lessons of q5Go by Bernd Schmidt (https://github.com/bernds/q5Go, `src/sgfs/`),
  GPL-2 (`lessons/COPYING-q5Go-GPL-2.txt`). Unchanged.
* `problems/easy`, `problems/intermediate`, `problems/hard` -- Go Game Guru's Weekly Go Problems
  (https://github.com/gogameguru/go-problems), Creative Commons Attribution-NonCommercial-ShareAlike 4.0
  (`problems/LICENSE-gogameguru-CC-BY-NC-SA-4.0.txt`). Unchanged; non-commercial use only.
* `problems/xuanxuan` -- the 347 problems of the Xuanxuan Qijing (Yan Defu and Yan Tianzhang, 1349), as encoded in
  SGF by MyGoGrinder 2.3.1 (https://sourceforge.net/projects/mygogrinder/, GPL). Unchanged.
